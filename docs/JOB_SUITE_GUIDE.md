# Active job suite guide

**Only CIFAR-100 v3 is active.** The old individual CIFAR-10 and CIFAR-100 job list documents were removed because their stage-based schedules did not satisfy the requested sequential local tasks per communication interval. The current job registry is generated by `src/cafcl/full_matrix.py` and indexed by deterministic `ST_<family>_<fingerprint>` IDs.

To see all exact configurations without CIFAR downloads: `bash scripts/run_all_cifar100.sh --plan-only --export-plan outputs/cifar100_deit_v4.jsonl.gz`.

The 53,805 configured jobs include a matched 5,346-run core and dedicated additional finite sweeps. See [FACTORIAL_SUITE.md](FACTORIAL_SUITE.md) for every research family and parameter range and [OVERLAP_CASES.md](OVERLAP_CASES.md) for all class-recurrence geometries. [CLASS_INDEXED_PAIR_PROTOCOL.md](CLASS_INDEXED_PAIR_PROTOCOL.md) explains private CL state, class-specific server weights and final flush.

**All planning is reproducible, but none of these 53,805 CIFAR-100 runs is claimed to have completed training.**
